// BudgetPace.kt
enum class PaceStatus { NO_BUDGET, UNDER, ON_TRACK, OVER }

Regras de `SmartAlerts`: nada no horário silencioso; `key` estável para não repetir (ex.: `budget80:2026-11:FOOD`);
resumo de revisão no máximo 1x/dia a partir das 19h se houver pendências (um aviso agrupado, nunca um por lançamento);
orçamento 80% e 100% uma vez por mês por categoria; conta recorrente vencendo amanhã uma vez; gasto incomum (> 3x a
mediana da categoria em 90 dias, mínimo R$ 50) uma vez por lançamento; captura parada (ativada, sem captura há 48h e
não saudável); resumo semanal domingo a partir das 18h; corta em `maxPerDay - sentToday` pela prioridade.
Textos sem valores de outros apps; títulos curtos em português.

### Dados (`LedgerRepository.kt`, `LedgerViewModel.kt`, `LedgerBackup.kt`)

- Tags: banco v9, tabela `transaction_tags(transaction_id TEXT NOT NULL, tag TEXT NOT NULL, PRIMARY KEY(transaction_id, tag))`;
  apagar junto com o lançamento e no `clear()`; entra no backup (restore aceita backup antigo sem tags).
  Repo: `val tags: StateFlow<Map<String, Set<String>>>`, `suspend fun setTags(id: String, tags: Set<String>)`.
  VM: `val tags`, `fun setTags(id: String, tags: Set<String>)`.
- `suspend fun recategorizeMerchant(id: String, category: Category): Int` — mesma chave de estabelecimento
  (a usada por `merchant_categories`), aprende e devolve quantos mudaram. VM: `fun recategorizeMerchant(id, category, onDone: (Int) -> Unit)`.
- `suspend fun confirmBatch(ids: List<String>, method: PaymentMethod?)` — confirma pendências cujo único dado faltante é o
  meio (aplica [method]) ou que já estão completas; ignora o resto. VM: `fun confirmBatch(ids, method, onDone: (Int) -> Unit)`.
- Preferências (SharedPreferences já usadas): `cardClosingDay: StateFlow<Int?>`, `cardDueDay: StateFlow<Int?>`,
  `setCardCycle(closing: Int?, due: Int?)`; `enum class HomeCard { PACE, CAPTURE, CREDIT, VR, RECENT, CHARTS }` em
  `LedgerRepository.kt`, `homeCards: StateFlow<List<HomeCard>>` (ordem) e `hiddenHomeCards: StateFlow<Set<HomeCard>>`,
  `setHomeCards(order, hidden)`; alertas: `alertsEnabled: StateFlow<Set<String>>` (nomes de `AlertKind`, padrão todos),
  `alertQuietHours: StateFlow<Pair<Int, Int>>` (22 a 8), setters, e `sentAlertKeys`/`markAlertSent(key, at)` com poda de 60 dias,
  `lastCaptureAt: StateFlow<Long?>` se ainda não existir equivalente. Tudo exposto também no VM.
